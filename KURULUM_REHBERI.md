# 🚀 Gözetim - Kurulum Rehberi (Supabase Versiyonu)

Bu rehber, Gözetim Ebeveyn Kontrol Sistemini **Supabase** altyapısı ile kurmak için hazırlanmıştır.

## 📋 Gereksinimler
- **Node.js** (Web panel için)
- **Supabase Hesabı** (Ücretsiz)
- **Android Studio** (Mobil uygulama için)

---

## 🔥 ADIM 1: Supabase Projesi Oluşturma

### 1.1 Proje Kurulumu
1. [Supabase](https://supabase.com) adresine gidin ve giriş yapın
2. **"New Project"** butonuna tıklayın
3. İsim: `Gozetim`
4. Veritabanı şifresini belirleyin ve **bölge** seçin (Size en yakın olanı)
5. **"Create new project"** diyerek oluşturun

### 1.2 Tabloları Oluşturma (SQL Editor)
Sol menüden **SQL Editor**'e gidin ve aşağıdaki SQL kodunu yapıştırıp **RUN** butonuna basın:

```sql
-- Kullanıcı profilleri
CREATE TABLE profiles (
  id UUID REFERENCES auth.users(id) PRIMARY KEY,
  email TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- Cihazlar
CREATE TABLE devices (
  device_id TEXT PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id),
  name TEXT,
  model TEXT,
  manufacturer TEXT, 
  android_version TEXT,
  battery_level INT,
  is_online BOOLEAN,
  last_seen TIMESTAMP WITH TIME ZONE,
  registered_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- Yüklü Uygulamalar
CREATE TABLE installed_apps (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  device_id TEXT REFERENCES devices(device_id) ON DELETE CASCADE,
  package_name TEXT NOT NULL,
  app_name TEXT,
  icon_char TEXT,
  status TEXT DEFAULT 'allowed', -- allowed, limited, blocked
  daily_limit_minutes INT,
  usage_today_minutes INT DEFAULT 0,
  usage_week_minutes INT DEFAULT 0,
  last_updated TIMESTAMP WITH TIME ZONE,
  UNIQUE(device_id, package_name)
);

-- Konum Geçmişi
CREATE TABLE location_history (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  device_id TEXT REFERENCES devices(device_id) ON DELETE CASCADE,
  latitude DOUBLE PRECISION,
  longitude DOUBLE PRECISION,
  address TEXT,
  accuracy FLOAT,
  timestamp TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- Row Level Security (RLS) Etkinleştirme
ALTER TABLE devices ENABLE ROW LEVEL SECURITY;
ALTER TABLE installed_apps ENABLE ROW LEVEL SECURITY;
ALTER TABLE location_history ENABLE ROW LEVEL SECURITY;

-- Politikalar (Şimdilik test için herkese açık yapıyoruz, production'da user_id kontrolü ekleyin)
CREATE POLICY "Public Access" ON devices FOR ALL USING (true);
CREATE POLICY "Public Access" ON installed_apps FOR ALL USING (true);
CREATE POLICY "Public Access" ON location_history FOR ALL USING (true);
```

### 1.3 API Anahtarlarını Alma
1. Sol menüden **Project Settings** (Dişli ikonu) -> **API** yolunu izleyin
2. `Project URL` ve `anon` `public` key'i kopyalayın

## 🌐 ADIM 2: Web Panel Kurulumu

1. `web-panel/app.js` dosyasını açın
2. En üstteki `supabaseConfig` bölümünü güncelleyin:

```javascript
const supabaseConfig = {
    url: "https://SİZİN-PROJE-ID.supabase.co",
    key: "SİZİN-ANON-KEY"
};
```

3. Web paneli başlatın:
```bash
npx serve
```

## 📱 ADIM 3: Android Uygulaması Kurulumu

### 3.1 Bağımlılıkları Ekleme
`android-app/app/build.gradle` dosyasını açın ve dependency'leri ekleyin:

```gradle
dependencies {
    // Retrofit (Network)
    implementation 'com.squareup.retrofit2:retrofit:2.9.0'
    implementation 'com.squareup.retrofit2:converter-gson:2.9.0'
    
    // ... diğerleri (Location vb.)
}
```

### 3.2 Sabitleri Güncelleme
`android-app/utils/SupabaseHelper.java` dosyasını açın ve sabitleri güncelleyin:

```java
private static final String SUPABASE_URL = "https://SİZİN-PROJE-ID.supabase.co/";
private static final String SUPABASE_KEY = "SİZİN-ANON-KEY";
```

### 3.3 Çalıştırma
Android Studio ile uygulamayı derleyin ve telefona yükleyin.
